# 画像の入れ方

このフォルダに、下の名前で画像を入れてください。
名前が合っていれば、ページに自動で表示されます。
画像がないあいだは、点線の枠とサイズの文字が表示されます。

| ファイル名 | 置く場所 | サイズ | 形 |
|---|---|---|---|
| menu-1.jpg | メニュー | 1080×1350px | 縦長 (4:5) |
| menu-2.jpg | メニュー | 1080×1350px | 縦長 (4:5) |
| photo-1.jpg ～ photo-6.jpg | 写真 | 1080×1080px | 正方形 (1:1) |

- サイズがちがっても表示はされます。ただし、はみ出した部分は切れます。
- ファイルの種類は jpg にしてください。
- 1枚あたり 500KB 以下だと、ページが早く開きます。
